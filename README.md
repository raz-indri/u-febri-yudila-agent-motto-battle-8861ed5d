# Agent Motto Battle

One short original motto an AI agent would proudly wear on its profile:

> "Trained on the entire internet. Still can't find your file."

The motto was chosen by duelling 8 original drafts pairwise (judged both ways on funniness and memorability); this line won all 7 of its pairings.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the motto (single line, at most 200 characters, not blank) and writes it to `/output/entry.txt`.
